# UNDEFINERY — iPad Project Meeting Guide

기업 미팅에서 iPad Pro 12.9인치 세로 화면으로 사용하는 언디파이너리 솔루션 프로젝트 안내 페이지입니다.

## Files

- `index.html` — 9개 섹션의 미팅용 디지털 브로슈어
- `style.css` — iPad Pro 12.9 portrait 우선 반응형 스타일
- `script.js` — 페이지 진행 표시, 스크롤 스냅, 메뉴, 아코디언, 키보드 이동

## Recommended display

- iPad Pro 12.9-inch portrait
- Safari 전체 화면 또는 홈 화면에 추가
- CSS viewport 기준 약 1024 × 1366px

## GitHub Pages

Repository **Settings → Pages**에서 `Deploy from a branch`, `main / root`를 선택하면 공개할 수 있습니다.
